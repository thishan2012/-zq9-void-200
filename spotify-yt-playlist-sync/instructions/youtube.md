# YouTube setup

1. Google Cloud Console → create/select a project → enable **YouTube Data API v3**.
2. Create an API key, restrict it to YouTube Data API v3. Avoid IP restrictions (GitHub runner IPs change).
   Monitor quota: a 200-video playlist costs 4 `playlistItems` pages + 4 `videos` batches.
3. Repo → Settings → Secrets and variables → Actions → secret `YOUTUBE_API_KEY`.
4. Set the source playlist URL in `.github/workflows/sync.yml` (`YOUTUBE_PLAYLIST`) or as a repository
   variable. Public and unlisted playlists work with an API key.

Pagination: `playlistItems.list` returns at most 50 items per page and is looped with `nextPageToken`
(200 videos = 4 pages); the log prints the page count. Descriptions and durations come from `videos.list`
in batches of 50. This is the official API, not yt-dlp. The YouTube side is **read-only** — nothing is
ever written back to YouTube.

Artist detection order: explicit credit in the description (`Artist: X`, `X - Song`, autogenerated
`Song · Artist 1 · Artist 2`) → `X - Topic` channel → `Artist - Song` title pattern. Generic channels such
as `Release - Topic` are not treated as artists.

There are three matching methods, tried in order:

1. **Strict** — search `artist + title`, require the same normalized title, the same version markers, and
   the primary artist.
2. **Loose** — search the full video title, pick the closest title above 0.86 similarity; version markers
   must still agree, named remixes need the full normalized title, close ties are skipped.
3. **Detail** — search the core title with version words removed, allow different word order, require
   ≥ 0.86 with artist / ≥ 0.93 without, and reject candidates whose duration differs by more than
   `max(30 s, 25 %)`. Close ties are skipped.

Logs label matches `MANUAL MATCH`, `STRICT MATCH`, `LOOSE MATCH`, `DETAIL MATCH` or `SKIP`, and the
Telegram full log repeats that per song. No matching method uses audio fingerprinting.

## Manually selected tracks

`data/track-overrides.json` maps a YouTube video ID to a Spotify track ID (`FGys9rRBytU` → PARAISO is
included). Overrides win over automatic matching and are labelled `MANUAL`. Confirm the recording and
version yourself: they bypass the title/version/duration checks. Duplicate checks and pending safeguards
still apply. Malformed entries stop the run.
